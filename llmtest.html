说明

本工具用于测试任何兼容 OpenAI API 格式的大模型接口。所有请求直接从浏览器发送到目标 API，API Key 仅保存在本地，不会上传至本服务器。

支持的接口格式

  • GET /v1/models — 获取可用模型列表
  • POST /v1/chat/completions — 流式对话（SSE）

使用提示

  • API URL 需包含协议头（如 https://），路径以 /v1 结尾。
  • 如果接口支持 CORS，可直接在浏览器中调用；否则需确保本站点在允许列表中。
  • 本地 Ollama 默认地址为 http://localhost:11434/v1，需开启 CORS。
  • 流式输出实时显示，可随时点击"停止"中断生成。
