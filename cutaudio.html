说明

  • 本工具基于 Web Audio API 构建，所有音频处理操作均在您的本地设备完成，无需上传至任何服务器，确保您的音频文件隐私安全。
  • 支持的输入格式取决于浏览器对音频格式的解码能力，常见格式如 MP3、WAV、AAC、OGG、FLAC 等一般均可正常处理。
  • 裁剪后的音频统一输出为 WAV 格式（PCM 16bit 立体声/单声道），以确保最佳兼容性。
  • 时间格式支持 HH:mm:ss.SSS，也可简写为纯秒数（如输入 90.5 表示 1分30秒500毫秒）。
  • 开始时间必须小于结束时间，且结束时间不得超过音频总时长。
